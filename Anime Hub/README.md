# 🎉 Anime Hub

Welcome to **Anime Hub** — your one-stop destination for discovering, tracking, and exploring your favorite anime series!

---

## 🌟 Features

- **Browse:** Curated lists of popular, trending, and seasonal anime.
- **Search:** Find anime by title, genre, or year.
- **Details:** View synopsis, episode count, ratings, trailers, and more.
- **Watchlist:** Add anime to your personal watchlist and track progress.
- **Responsive:** Optimized for desktop, tablet, and mobile devices.
- **API Integration:** Fetches live data from [Jikan API](https://jikan.moe/).

## 📦 Getting Started

1. **Clone the repository:**
   ```
   git clone https://github.com/kuro-shiv/Anime-Hub.git
   ```
2. **Install dependencies (if any):**
   ```
   npm install
   ```
3. **Run locally:**
   ```
   npm start
   ```
   Or simply open `index.html` in your browser for static usage.

---

## 🛠️ Usage

- Browse anime lists from the homepage.
- Use the search bar to find specific anime.
- Click on any anime card for detailed information.
- Add anime to your watchlist (local storage).
- Enjoy a seamless experience across devices.
