# 📖 Story Page

Welcome to the **Story Page** project! This web app lets you read, share, and create engaging stories in a beautiful, interactive format.

---

## 🌟 Features

- **Read Stories:** Browse a curated collection of short stories and tales.
- **Create Stories:** Submit your own stories using a simple form.
- **Interactive UI:** Enjoy a clean, responsive design for all devices.
- **Categories & Tags:** Filter stories by genre, theme, or tags.
- **Share:** Easily share your favorite stories with friends.
- **Favorites:** Mark stories you love and revisit them anytime.
- **Comments:** Leave feedback and discuss stories with others.
- **Dark Mode:** Switch between light and dark themes for comfortable reading.

## 📦 Getting Started

1. **Clone the repository:**
   ```
   git clone https://github.com/kuro-shiv/Story_Page.git
   ```
2. **Open `index.html` in your browser** to start reading and creating stories.

---

## 🛠️ Usage

- Browse stories from the homepage.
- Use the form to submit your own story.
- Filter stories by category, theme, or tags.
- Mark stories as favorites for quick access.
- Leave comments and join the discussion.
- Share stories using the share button.
- Toggle dark mode for a better reading experience.
