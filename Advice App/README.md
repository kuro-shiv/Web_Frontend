# 📝 Advice App

This project is a simple React application that fetches random advice using a public API. It features a clean UI and uses Node.js for development and API integration.

## 🚀 Features

- Fetches random advice from an external API
- Simple and user-friendly interface
- Built with React for fast and interactive UI
- Responsive design for all devices

## 🛠️ Technologies Used

- React
- Node.js
- Advice Slip API

## 📦 Getting Started

1. **Clone the repository:**
   ```
   git clone https://github.com/kuro-shiv/Advice-App.git
   ```
2. **Install dependencies:**
   ```
   npm install
   ```
3. **Run the app locally:**
   ```
   npm start
   ```

## 📚 Usage

- Click the button to get a new piece of advice.
- Enjoy a simple and clean user experience.
