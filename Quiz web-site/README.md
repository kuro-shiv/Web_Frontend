# 🧠 Quiz Website

Welcome to the **Quiz Website** — an interactive platform to test your knowledge on various topics! Challenge yourself, learn new facts, and track your progress.

---

## 🌟 Features

- **Multiple Categories:** Choose from a variety of quiz topics (General Knowledge, Science, History, etc.)
- **Difficulty Levels:** Select easy, medium, or hard questions.
- **Timed Quizzes:** Race against the clock for extra challenge.
- **Instant Feedback:** See correct answers and explanations after each question.
- **Score Tracking:** View your score and progress at the end of each quiz.
- **Responsive Design:** Works seamlessly on desktop, tablet, and mobile.
- **Question API Integration:** Fetches live questions from [Open Trivia DB](https://opentdb.com/) or similar APIs.

## 📦 Getting Started

1. **Clone the repository:**
   ```
   git clone https://github.com/kuro-shiv/Quiz-web-site.git
   ```
2. **Install dependencies (if any):**
   ```
   npm install
   ```
3. **Run locally:**
   ```
   npm start
   ```
   Or open `index.html` directly for static usage.

---

## 🛠️ Usage

- Select a quiz category and difficulty level.
- Answer each question within the time limit.
- Get instant feedback and explanations.
- View your final score and share your results.
