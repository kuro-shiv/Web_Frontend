# 🧠 JavaScript Project Collection

This repository contains a series of JavaScript-based mini applications created during my learning journey through a [Udemy Course](https://www.udemy.com/course/javascript-projects-course-build-20-projects-in-20-days/learn/lecture/39790898?start=0#overview).

Each project is self-contained, focused on solving real-world problems using JavaScript and strengthening my understanding of **DOM manipulation**, **logic building**, and **event-driven programming**.

## 📁 Project List

| Project Name                          | Description |
|--------------------------------------|-------------|
| **Age Calculator**                   | Calculate exact age in years, months, and days. |
| **BMI Calculator**                   | Computes Body Mass Index based on user input. |
| **Cash Calculator Application**      | Calculates remaining balance using entered denomination. |
| **Dictionary Application**           | Fetches word definitions using an API. |
| **Digital Clock**                    | Displays current time dynamically. |
| **Expense Tracker**                  | Tracks income and expenses with running balance. |
| **FD Calculator**                    | Calculates maturity amount and interest for fixed deposits. |
| **Loan Calculator**                  | Calculates EMI and total repayment. |
| **Mouse Zoom Application**           | Zoom in/out content using mouse wheel events. |
| **Notes Taking App (Sticky Notes)**  | Lets users create, edit, and delete sticky notes in-browser. |
| **Random Color Generator**           | Generates random colors and changes background. |
| **Random Paragraph Generator**       | Produces placeholder content for writing/design testing. |
| **Stopwatch Timer Application**      | Implements a stopwatch with start/pause/reset. |
| **Text Animation**                   | Animates text display with typing effect. |
| **Timer and Date Widget**            | Live time and date widget for UI enhancement. |
| **Tip Calculator**                   | Calculates tip amount and splits it among people. |
| **To-Do List**                       | Allows task adding, deletion, and completion status. |

> 📌 All apps are built using **vanilla JavaScript**, with clean HTML/CSS styling. No external frameworks used.
